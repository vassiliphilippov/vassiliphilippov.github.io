Etymology

Random-access memory gives the image of a shelf where you can take any item straight away; random-access means you can get data in 'any order' instead of following a set order. That's why random-access memory is the fast memory the computer uses while it is on to hold data it needs quickly, and why what is stored there is lost when you turn the computer off.
