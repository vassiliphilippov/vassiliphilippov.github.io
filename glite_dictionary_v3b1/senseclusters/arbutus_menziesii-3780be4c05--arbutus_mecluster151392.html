Etymology

Arbutus menziesii: The scientific name mixes the group name Arbutus, a type of tree with smooth red bark and orange berries, and the species name menziesii, which 'honors' the Scottish naturalist Archibald Menzies who first found and wrote about the tree, so the name simply tells us this is the Arbutus that Menzies discovered.
