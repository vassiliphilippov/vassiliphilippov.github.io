Etymology

Dual inline package switch is named for how it looks: a small rectangular package with two rows, which explain the dual and inline parts, and tiny on-off switches that sit like a chip on a circuit board. Because you flip those little switches by hand to change hardware 'settings', the name reminds you it is a physical control used instead of software.
