Etymology

The word unnilquadium comes from number parts: un- 'one', nil- 'zero', and quad- 'four', plus the ending -ium, like in calcium, which is common for metals. As a helpful memory hook, it literally reads 'one-zero-four', so it was a temporary name for element 104 before the official name rutherfordium.
