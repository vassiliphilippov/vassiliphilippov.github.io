Etymology

main beam headlamp gets its name from the parts main beam and headlamp, meaning a car's front light that sends a strong, central beam straight ahead. Because this bright, focused beam helps you see far on empty roads but can 'dazzle' other drivers, it is used only when there is no 'oncoming traffic'.
