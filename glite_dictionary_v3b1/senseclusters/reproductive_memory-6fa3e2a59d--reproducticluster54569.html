Etymology

reproductive memory uses reproductive in the sense of 'to reproduce', meaning to make a copy. Imagine a photocopier that gives the same page again; reproductive memory is the idea that the mind returns an 'exact copy' of what was seen or heard, not a memory that 'rebuilds' the event from pieces.
