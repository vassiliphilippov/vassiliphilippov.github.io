Etymology

The noun system of weights and measures comes from a time when towns kept one set of official tools so shopkeepers all used the same weights and measures. If a town had a standard bar, scale and stone in the town hall people could check their tools, so the phrase now means an organized set of 'units and standards' used to measure things.
