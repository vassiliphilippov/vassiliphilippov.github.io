Etymology

swap file comes from swap 'to exchange' and file meaning a place on the computer disk. Imagine your desk as the computer's fast memory, full of papers, and you put some papers in a box on the shelf called the swap file to make space and move them back when needed. That's why a swap file is a file on the disk the computer uses as extra memory.
