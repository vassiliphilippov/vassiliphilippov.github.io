Etymology

The saying run with the hare and hunt with the hounds comes from hunting scenes where a hare is the animal and the hounds are the dogs that chase it. If someone tries to run with the hare and hunt with the hounds at the same time, they are acting like they are on both sides, so today the phrase means 'to try to please or support two opposite sides at once'.
