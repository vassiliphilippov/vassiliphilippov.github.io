Etymology

circular file is a joking office name for a trash can. The name comes from circular, meaning 'round', and file, meaning 'place for papers'. Picture dropping unwanted pages into a round bin under the desk, so sending a document to the circular file means 'to throw it away' or 'ignore it'.
