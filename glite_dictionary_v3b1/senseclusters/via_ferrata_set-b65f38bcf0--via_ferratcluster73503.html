Etymology

via ferrata set comes from via ferrata climbing routes, which are paths fixed to the rock with metal cables and metal steps, and via ferrata means 'iron way'. The set is the special strap and two metal hooks called carabiners that you clip to the cable to stay attached if you slip, so the name means 'safety gear' for those routes.
