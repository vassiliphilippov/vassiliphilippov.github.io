Etymology

foot file comes from the simple idea of a small, rough file used on the foot. Imagine a metal file that smooths wood or metal; when a similar rough tool was used on the foot, it scraped away hard, dead skin. So a foot file is the tool for 'removing dead skin' from the soles of your feet.
