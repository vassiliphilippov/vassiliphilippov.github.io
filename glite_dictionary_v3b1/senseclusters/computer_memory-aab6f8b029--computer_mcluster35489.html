Synonyms

    7/m4.4
    Stores data and instructions electronically for use by digital processors
    vscomputer memory: is specific to storage meant directly for a single machine's processor
  • RAM
    1/m3.5
    Provides fast temporary storage while a system runs for immediate processing
    vscomputer memory: is the general storage device not limited to fast temporary use
  • memory chip
    0.1/m3.6
    Is a small integrated circuit that stores data electronically for processing
    vscomputer memory: refers to storage function in general rather than the physical circuit
  • memory device
    0.03/m3.5
    Is any piece of hardware used to store data for later retrieval
    vscomputer memory: focuses on storage directly serving a processor, not general archival hardware
  • virtual memory
    0.02/m4.2
    Uses part of a hard disk to simulate extra main storage for programs
    vscomputer memory: is actual electronic storage hardware rather than a disk-based simulation
  • memory cache
    0.01/m4.8
    Acts as a small fast buffer to speed transfers between components
    vscomputer memory: is the broader storage area used for all processor data and instructions
  • random memory
    0.00/m5.7
    Allows data access in any order for quick temporary use during operation
    vscomputer memory: is a broader storage device not defined by access order
  • read/write memory
    0.00/m4.2
    Permits both data change and retrieval for active temporary storage
    vscomputer memory: does not emphasize bidirectional access but names storage for processor use

Etymology

computer memory comes from comparing a computer to a person; long before machines, memory meant a person's power to 'remember' things, so early makers called the parts that 'store' data the computer's memory.
